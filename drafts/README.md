# drafts — דפים שלא הגיעו לאתר החי

תיקייה זו מרכזת דפים שקיימים אבל **אינם מקושרים לדף הבית ואינם מוצגים לגולשים** —
בדרך כלל דפים שלא הושלמו. שומרים אותם כאן כדי שנוכל לחזור אליהם ולהמשיך אם יהיה צורך,
מבלי למחוק עבודה קיימת ומבלי שהם ייכנסו בטעות לאתר.

הדפים כאן עדיין נבדקים ע"י בדיקת "Site checks" (תקינות HTML), אבל אף אחד לא מקשר אליהם,
אז הם לא נגישים מהאתר הרגיל.

## מה יש כאן

- **`ppt.html`** — "הכנת מצגות בעידן ה-AI": גלריה שאמורה להציג מצגות מוטמעות של
  Gamma App ו-Canva. הדף לא הושלם — קישורי ה-embed הם placeholders
  (`YOUR_GAMMA_EMBED_URL`, `YOUR_CANVA_EMBED_URL`) ולא הוזנו מצגות אמיתיות.
  כדי להחזיר אותו לאתר: להחליף את שני ה-`src` של ה-iframe בקישורי embed אמיתיים,
  להעביר בחזרה לשורש, ולהוסיף קישור מדף הבית.
